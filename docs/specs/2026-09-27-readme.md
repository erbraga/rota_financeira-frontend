## Problema
O repositório não tem `README.md`: quem chega nele (avaliador do trabalho, ou o próprio autor num clone
limpo) não tem por onde começar — nem descrição do projeto, nem como instalar, rodar, testar ou publicar em
contêiner. O R2 exige um README bem formatado com a imagem de um fluxograma da arquitetura mostrando um
cenário de uso; o R5 exige que ele cubra a instalação de ponta a ponta.

## Objetivo
Um `README.md` na raiz, formatado (cabeçalhos, listas, blocos de código), com tudo que uma pessoa precisa para
instalar, rodar (local e em Docker), testar e entender a SPA — incluindo o fluxograma da arquitetura (R2), já
existente em `docs/img/` (`arquitetura.dot`/`.png`/`.svg`, copiados pelo autor de fora deste repositório — **não
recriar**).

## Fora de escopo
- Recriar ou editar o fluxograma da arquitetura: os três arquivos em `docs/img/` (`arquitetura.dot`,
  `arquitetura.png`, `arquitetura.svg`) já existem, foram trazidos pelo autor de outro lugar (provavelmente o
  mesmo diagrama do backend, que já cobre a SPA, a API Flask, o PostgreSQL e o BACEN/SGS) e serão usados como
  estão. Só o `README.md` referencia a imagem.
- **Capturas de tela** (decisão do autor): o `plano.md` as lista como algo que "ajuda o R4", não como
  obrigatório — o README fica só com texto e o fluxograma.
- Mudar qualquer coisa de código, comportamento ou contrato — esta etapa é só documentação.
- Traduzir o README para outro idioma (fica em pt-BR, como o resto do projeto).
- Badges de CI, changelog, guia de contribuição (`CONTRIBUTING.md`) ou licença — não pedidos pelos requisitos.
